# Tesla Fleet public key

This repository publishes the public key used by the Tesla Fleet Vehicle Command Proxy.

Public key endpoint:

```text
https://tesla-control.wang948514333.top/.well-known/appspecific/com.tesla.3p.public-key.pem
```

Only the public key is stored here. Private keys, access tokens, vehicle identifiers, account details, and location data must never be committed.
